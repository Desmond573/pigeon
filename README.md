# Pigeon Post — Parcel Patrol

A tiny, original browser arcade game. No framework, build step, account, or external assets required.

## Play locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `pigeon-post`).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide your public game URL.

## Controls
- Desktop: WASD or arrow keys to move; Space to pause; R to restart.
- Mobile: use the on-screen directional buttons.
- Collect letters (up to 3), then touch a red postbox to deliver them.
- Avoid cats and bicycles. Puddles slow you down briefly.
- Best delivery count is saved in the browser using local storage.
